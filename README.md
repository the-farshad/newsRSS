# newsRSS

Read the [Kurdistan24](https://www.kurdistan24.net) RSS feeds and print the
title, publication date and lead image of each article.

## Requirements

- Python 3

Install the dependencies:

```sh
pip install -r requirements.txt
```

## Usage

```sh
python newsRSS.py
```
